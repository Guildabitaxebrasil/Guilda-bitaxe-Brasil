💡 Qual Bitaxe escolher?

O Gamma (BM1370) é o melhor custo-benefício: maior eficiência (~15 J/TH) e hashrate excelente para single-chip. O GT dobra a potência com dois chips, e o Hex é o mais potente com 6 chips. O Supra é a opção de entrada mais moderna e eficiente.

⚠️ Importante sobre alimentação

Modelos 5V (Ultra, Supra, Gamma) usam conector barril 5.5x2.1mm. Modelos 12V (GT, Hex) usam conector XT30. A porta USB-C é apenas para flash/debug, não para alimentação!

🛠️ Atualização de Firmware

Mantenha seu Bitaxe atualizado com a versão mais recente do ESP-Miner / AxeOS para obter as melhores funcionalidades e segurança.

✅ Stratum V2 ✅ mDNS (bitaxe.local) ✅ Fan Control ✅ Dashboard Novo ✅ Swarm Management

📥 Método A — OTA pela Web (Recomendado) ⭐

Atualização sem fio, preserva todas as configurações.

1
Acesse o dashboard do Bitaxe: http://<IP_DO_BITAXE> ou http://bitaxe.local
2
Vá em Settings → Update Firmware
3
Clique em Check Latest Releases ou baixe manualmente o esp-miner.bin
4
Selecione o arquivo e clique em Upload
5
Aguarde ~60 segundos — o Bitaxe reinicia sozinho ✅
💡 Arquivo correto para seu modelo

Baixe o arquivo com o número do seu modelo: esp-miner-factory-601-v2.14.x.bin para Gamma 601, -401 para Supra, etc.

📥 Método B — Bitaxe Web Flasher (USB Recovery)

Para recuperação (unbrick) ou primeira configuração via USB.

1
Conecte o USB-C ao PC (cabo de dados, não só de carga)
2
Coloque em modo bootloader: segure Boot, aperte Reset, solte Boot
3
Abra o Bitaxe Web Flasher no Chrome ou Edge
4
Conecte, selecione o modelo correto e clique Start Flashing
⚠️ Atenção

Flash via USB apaga todas as configurações (Wi-Fi, pool, wallet). Anote seus dados antes!

📥 Método C — bitaxetool (CLI)

Para usuários avançados que preferem linha de comando.

# Instalar versão compatível
$ pip install bitaxetool==0.6.1

# Flash completo (exemplo para Gamma 601)
$ bitaxetool --port COM6 --config ./config-601.cvs --firmware ./esp-miner-factory-601-v2.14.0.bin
⚠️ Compatibilidade

bitaxetool NÃO funciona com esptool v5.x! Use a versão 0.6.1 (travada com esptool v4.9.0).

🔥 Overclock Seguro

Aumente o desempenho do seu Bitaxe com segurança. Siga as etapas e respeite os limites térmicos.

🔓 Destravando as Configurações OC

No AxeOS, as opções de frequência e voltagem vêm ocultas por padrão. Para ativar:

# Adicione ?oc no final da URL de Settings
http://<IP_DO_BITAXE>/settings?oc

🌡️ Limites Térmicos

✅ 45-55°C Confortável ⚠️ 55-65°C Aceitável 🔶 65-70°C Atenção 🔴 70-75°C Throttling ☠️ 75°C+ PERIGO
☠️ Regras de Ouro da Voltagem

✅ Máximo seguro 24/7: 1250 mV
⚠️ Limite absoluto: 1300 mV
☠️ Acima disso = risco de danificar o chip (electromigration)!

📈 Procedimento Passo a Passo

1
Teste de Baseline (24h): Deixe rodando em stock. Anote hashrate, temperatura e erros.
2
Aumente +25 MHz por vez: Suba a frequência em etapas de 25 MHz. Espere 15-20 min entre cada passo.
3
Monitore: Erros < 1-2% e temperatura estável = ✅. Queda de hashrate ou reboots = ❌ volte 25 MHz.
4
Adicione voltagem (se necessário): Suba +25~50 mV, mas nunca ultrapasse 1300 mV.
5
Validação final (72h): Rode por 72 horas para confirmar estabilidade em diferentes temperaturas ambiente.
🎯 Recomendação para Iniciantes

Comece com 600 MHz / 1150 mV — ganho de ~1.3 TH/s sem precisar trocar fonte ou cooling. Depois que pegar confiança, suba para 700 MHz com uma fonte Mean Well LRS-50-5.

🌐 Pools de Mineração

Configure seu Bitaxe para minerar em pool ou solo. Para dispositivos de baixo hashrate como Bitaxe, a mineração solo (CKPool) funciona como um bilhete de loteria.

⚙️ Configuração Básica

1
Acesse o dashboard: http://<IP_DO_BITAXE> → Settings
2
Preencha Stratum URL e Stratum Port do pool escolhido
3
No campo Username, coloque seu endereço Bitcoin (começa com bc1...)
4
Password: deixe em branco ou coloque x
5
Salve e reinicie. Pronto! ✅

🔄 Stratum V2

O Bitaxe suporta o novo protocolo Stratum V2, que traz mais eficiência, segurança e melhor comunicação com o pool.

# Exemplo de configuração SV2 via API
curl -X PUT http://<BITAXE-IP>/api/system/pools/1 \
  -H "Content-Type: application/json" \
  -d '{
   "stratumProtocol": "SV2",
   "stratumURL": "v2.srtm.ocean.xyz",
   "stratumPort": 3334,
   "stratumUser": "<SUA_WALLET>",
   "stratumPassword": "x"
  }'
💡 Para Bitaxe, recomendamos

CKPool Solo — como o hashrate é baixo, a mineração em pool tradicional renderia centavos por mês. No solo, você tem chance de acertar um bloco e ganhar 3.125 BTC de uma vez! 🎰

🚨 Troubleshooting

Problemas comuns e soluções rápidas para seu Bitaxe.

🔄 Reboots aleatórios
Causa: Fonte insuficiente
✅ Troque para fonte de 50W (Mean Well LRS-50-5)
🔥 VRM > 90°C
Causa: MOSFETs sem dissipador
✅ Adicione heatsinks nos VRMs
❌ Muitos shares rejeitados
Causa: Voltagem baixa p/ frequência
✅ Aumente +25mV ou diminua -25MHz
📉 Hashrate oscilando
Causa: Throttling térmico
✅ Melhore o cooling (heatsink, pasta, fan)
⚙️ Não aparece ?oc
Causa: URL errada
✅ Digite /settings?oc na barra de endereço
🌐 Não acha o Bitaxe
Causa: Roteador bloqueando
✅ Desligue AiProtection/IoT Protection
🔌 USB-C não reconhece
Causa: Problema conhecido
✅ Use adaptador USB-A para USB-C
🥶 Bitaxe muito quente
Causa: Pasta térmica original fraca
✅ Troque por Thermal Grizzly Kryonaut
📡 Sem hash após configurar
Causa: Pool configurado errado
✅ Verifique URL, porta e wallet do pool
📱 Não consigo acessar o IP
Causa: Bitaxe em rede diferente
✅ Use o app Fing para descobrir o IP

❓ Perguntas Frequentes

As dúvidas mais comuns sobre Bitaxe.

O que é Bitaxe? ▼
Bitaxe é um minerador ASIC open-source de Bitcoin, do tamanho de uma xícara. Ele usa chips reciclados de Antminers e um ESP32-S3 para controlar tudo. Ideal para mineração solo (loteria) ou aprendizado.
Quanto um Bitaxe ganha por dia? ▼
Com 1.2 TH/s (Gamma), em um pool tradicional você ganharia centavos por mês. Por isso a maioria usa mineração solo (CKPool) — cada bloco encontrado paga 3.125 BTC (~R$ 1 milhão+). É um bilhete de loteria com custo de ~R$ 10/mês de energia!
Precisa de computador ligado 24h? ▼
Não! O Bitaxe é independente — conecta via Wi-Fi direto no pool. O computador só é necessário para configuração inicial e atualizações de firmware.
Qual a diferença entre os modelos? ▼
Cada modelo usa um ASIC diferente: Ultra (BM1366), Supra (BM1368), Gamma (BM1370). O Gamma é o mais potente e eficiente (~15 J/TH). O GT tem 2 chips BM1370. O Hex tem 6 chips BM1366. A compatibilidade de firmware varia, sempre baixe o arquivo correto para seu modelo (601, 401, etc).
Bitaxe funciona com qualquer roteador? ▼
A maioria funciona, mas roteadores ASUS e TP-Link podem bloquear mineração. Desligue AiProtection (ASUS) e IoT Protection (TP-Link) se tiver problemas.
Overclock danifica o Bitaxe? ▼
Overclock moderado (até 1250 mV e 65°C) é seguro para uso 24/7. O risco aumenta acima de 1300 mV (electromigration) ou 70°C (degradação térmica). Siga as etapas do guia de overclock com paciência.
Qual fonte usar? ▼
Modelos 5V (Gamma, Supra, Ultra): fonte 5V / 6A+ (30W+), ex: Mean Well LRS-50-5. Modelos 12V (GT, Hex): fonte 12V / 10A+ (120W+) com conector XT30. A porta USB-C é apenas para dados/flash.
Como faço para atualizar o firmware? ▼
A maneira mais fácil é pelo próprio dashboard (OTA): Settings → Update Firmware → upload do arquivo .bin. Também pode usar o Bitaxe Web Flasher via USB (Chrome/Edge) ou o bitaxetool via terminal.
O que é mDNS? ▼
mDNS permite acessar seu Bitaxe pelo nome em vez do IP. Depois de configurar, use http://bitaxe.local no navegador. Muito útil se o IP mudar!
Posso minerar outras criptomoedas? ▼
O Bitaxe minerada apenas SHA-256 (Bitcoin, Bitcoin Cash, Bitcoin SV). Não minera Ethereum, Litecoin ou outras moedas com algoritmos diferentes.
