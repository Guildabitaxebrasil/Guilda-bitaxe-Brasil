💡 Qual Bitaxe escolher?

O Gamma (BM1370) é o melhor custo-benefício: maior eficiência (~15 J/TH) e hashrate excelente para single-chip. O GT dobra a potência com dois chips, e o Hex é o mais potente com 6 chips. O Supra é a opção de entrada mais moderna e eficiente.

🛠️ Atualização de Firmware

Mantenha seu Bitaxe atualizado com a versão mais recente do ESP-Miner / AxeOS para obter as melhores funcionalidades e segurança.

✅ Stratum V2✅ mDNS (bitaxe.local)✅ Fan Control✅ Dashboard✅ Swarm

📥 Método A — OTA pela Web ⭐ Recomendado

Atualização sem fio — preserva todas as configurações.

1
Acesse o dashboard: http://<IP_DO_BITAXE> ou http://bitaxe.local
2
Vá em Settings → Update Firmware
3
Clique em Check Latest Releases ou baixe o esp-miner.bin
4
Selecione o arquivo e clique Upload
5
Aguarde ~60s — o Bitaxe reinicia sozinho ✅
💡 Arquivo correto

Baixe com o número do seu modelo: esp-miner-factory-601-v2.14.x.bin (Gamma 601), -401 (Supra), etc.

📥 Método B — Web Flasher (USB Recovery)

Para recuperação (unbrick) ou primeira configuração.

1
Conecte o USB-C ao PC (cabo de dados)
2
Modo bootloader: segure Boot + aperte Reset + solte Boot
3
Abra o Bitaxe Web Flasher no Chrome ou Edge
4
Conecte, selecione o modelo e clique Start Flashing
⚠️ Atenção

Flash USB apaga todas as configurações (Wi-Fi, pool, wallet). Anote seus dados antes!

📥 Método C — bitaxetool (CLI)

# Instalar versão compatível
$ pip install bitaxetool==0.6.1

# Flash Gamma 601
$ bitaxetool --port COM6 --config ./config-601.cvs --firmware ./esp-miner-factory-601-v2.14.0.bin
⚠️ Compatibilidade

bitaxetool NÃO funciona com esptool v5.x! Use a versão 0.6.1 (travada com esptool v4.9.0).

🔥 Overclock Seguro

Aumente o desempenho do seu Bitaxe com segurança. Siga as etapas e respeite os limites térmicos.

🔓 Destravando Configurações OC

Adicione ?oc no final da URL de Settings:

http://<IP_DO_BITAXE>/settings?oc

🌡️ Limites Térmicos

✅ 45-55°C ⚠️ 55-65°C 🔶 65-70°C 🔴 70-75°C ☠️ 75°C+
☠️ Regras de Ouro da Voltagem

✅ Máximo 24/7: 1250 mV  |  ⚠️ Limite absoluto: 1300 mV  |  ☠️ Acima disso = risco de danificar o chip!

📈 Procedimento

1
Baseline (24h): Rode em stock. Anote hashrate, temperatura e erros.
2
Aumente +25 MHz por vez. Espere 15-20 min entre cada passo.
3
Monitore: Erros < 2% e temp estável = ✅. Queda/reboot = ❌ volte 25 MHz.
4
Voltagem: Suba +25~50 mV se necessário. Nunca > 1300 mV!
5
Validação (72h): Rode 72h para confirmar estabilidade.
🎯 Recomendação Inicial

600 MHz / 1150 mV → ~1.3 TH/s sem trocar fonte ou cooling. Depois suba para 700 MHz com fonte Mean Well LRS-50-5.

O Bitaxe suporta o novo protocolo Stratum V2 — mais eficiente e seguro.

curl -X PUT http://<BITAXE-IP>/api/system/pools/1 \
  -H "Content-Type: application/json" \
  -d '{"stratumProtocol":"SV2","stratumURL":"v2.srtm.ocean.xyz","stratumPort":3334,"stratumUser":"<SUA_WALLET>","stratumPassword":"x"}'

🚨 Troubleshooting

Problemas comuns e soluções rápidas para seu Bitaxe.

🔄 Reboots aleatórios
Causa: Fonte insuficiente
✅ Troque para fonte 50W (Mean Well LRS-50-5)
🔥 VRM > 90°C
Causa: MOSFETs sem dissipador
✅ Adicione heatsinks nos VRMs
❌ Muitos shares rejeitados
Causa: Voltagem baixa p/ frequência
✅ +25mV ou -25MHz
📉 Hashrate oscilando
Causa: Throttling térmico
✅ Melhore o cooling
⚙️ Não aparece ?oc
Causa: URL errada
✅ Digite /settings?oc na barra
🌐 Não acha o Bitaxe
Causa: Roteador bloqueando
✅ Desligue AiProtection/IoT Protection
🔌 USB-C não reconhece
Causa: Problema conhecido
✅ Use adaptador USB-A → USB-C
🥵 Bitaxe muito quente
Causa: Pasta térmica original fraca
✅ Troque por Thermal Grizzly Kryonaut
📡 Sem hash após configurar
Causa: Pool configurado errado
✅ Verifique URL, porta e wallet
📱 Não acho o IP
Causa: Bitaxe em rede diferente
✅ Use app Fing para descobrir

❓ Perguntas Frequentes

As dúvidas mais comuns sobre Bitaxe.

O que é Bitaxe? ▼
Bitaxe é um minerador ASIC open-source de Bitcoin, do tamanho de uma xícara. Usa chips reciclados de Antminers e um ESP32-S3. Ideal para mineração solo (loteria) ou aprendizado. Conecta via Wi-Fi direto no pool — não precisa de PC ligado!
Quanto um Bitaxe ganha por dia? ▼
Com 1.2 TH/s (Gamma), em pool tradicional seriam centavos por mês. Por isso a maioria usa mineração solo (CKPool) — cada bloco paga 3.125 BTC (~R$ 1 milhão+). É um bilhete de loteria com custo de ~R$ 10/mês de energia!
Precisa de computador ligado 24h? ▼
Não! O Bitaxe é independente — conecta via Wi-Fi direto no pool. O computador só é necessário para configuração inicial e atualizações de firmware.
Qual a diferença entre os modelos? ▼
Cada modelo usa um ASIC diferente: Ultra (BM1366), Supra (BM1368), Gamma (BM1370). O Gamma é o mais eficiente (~15 J/TH). O GT tem 2 chips BM1370. O Hex tem 6 chips BM1366. Sempre baixe o firmware correto para seu modelo (601, 401, etc).
Bitaxe funciona com qualquer roteador? ▼
A maioria funciona, mas roteadores ASUS e TP-Link podem bloquear mineração. Desligue AiProtection (ASUS) e IoT Protection (TP-Link) se tiver problemas.
Overclock danifica o Bitaxe? ▼
Overclock moderado (até 1250 mV e 65°C) é seguro 24/7. Risco aumenta acima de 1300 mV (electromigration) ou 70°C. Siga o guia com paciência e respeite os limites térmicos.
Qual fonte usar? ▼
Modelos 5V: fonte 5V / 6A+ (30W+), ex: Mean Well LRS-50-5. Modelos 12V (GT, Hex): fonte 12V / 10A+ com XT30. USB-C é apenas para dados/flash, não alimenta o Bitaxe!
Como atualizar o firmware? ▼
Pelo dashboard (OTA): Settings → Update Firmware → upload do .bin. Ou use o Bitaxe Web Flasher via USB (Chrome/Edge). Ou bitaxetool via terminal.
O que é mDNS? ▼
Permite acessar pelo nome em vez do IP. Use http://bitaxe.local no navegador. Muito útil se o IP mudar!
Posso minerar outras moedas? ▼
O Bitaxe minera apenas SHA-256 (Bitcoin, Bitcoin Cash, Bitcoin SV). Não minera Ethereum, Litecoin ou outras moedas.
