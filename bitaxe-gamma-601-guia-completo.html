🛠️ Atualização de Firmware

📦 Versão Atual

A versão mais recente do ESP-Miner / AxeOS é a v2.14.x (Julho 2026).

✅ Stratum V2 ✅ mDNS (bitaxe.local) ✅ Fan Control Melhorado ✅ Dashboard Aprimorado

📥 Método A — OTA pela Web (Recomendado) ⭐

1. Acesse o dashboard: http://<IP_DO_BITAXE>
2. Vá em Settings → Update Firmware
3. Clique em Check Latest Releases ou baixe o esp-miner.bin
4. Selecione o arquivo e clique Upload
5. Aguarde ~60s — ele reinicia sozinho ✅
💡 Vantagem: O OTA preserva todas as configurações (Wi-Fi, pool, wallet)!

📥 Método B — Bitaxe Web Flasher (USB)

Melhor para recuperação (unbrick) ou primeira configuração.

1. Conecte o USB-C ao PC (cabo de dados)
2. Coloque em modo bootloader:
🔘 Segure Boot + aperte Reset + solte Boot
3. Abra o Bitaxe Web Flasher no Chrome/Edge
4. Conecte, selecione o modelo 601 e clique Start Flashing
⚠️ Atenção: Flash via USB apaga todas as configurações! Anote seu SSID e senha antes.

📥 Método C — bitaxetool (CLI Python)

# Instalar (versão compatível com esptool v4.9.0)
$ pip install bitaxetool==0.6.1

# Flash completo no Gamma 601
$ bitaxetool --port COM6 --config ./config-601.cvs --firmware ./esp-miner-factory-601-v2.14.0.bin
⚠️ Importante: bitaxetool NÃO funciona com esptool v5.x! Use a versão 0.6.1.

📈 Passo a Passo do Overclock

🔹 Fase 1: Apenas Frequência

Aumente +25 MHz por vez, esperando 15-20 min entre cada passo:

Passo 1: Stock → 525 MHz (baseline)
Passo 2: +25 MHz → 550 MHz ✅ (rode 15-20 min)
Passo 3: +25 MHz → 575 MHz ✅ (rode 15-20 min)
Passo 4: +25 MHz → 600 MHz ✅ (rode 15-20 min)
... Continue até notar instabilidade
✅ Sinal de estabilidade: Erros < 1-2%, temperatura ok, hashrate constante
❌ Sinal de instabilidade: Hashrate caindo, shares rejeitados, reboot

🔹 Fase 2: Adicionar Voltagem

Quando bater no muro da frequência, você tem 2 opções:

😌 Opção Conservadora
Volte 25 MHz
Risco: ✅ Muito seguro
😈 Opção Agressiva
+25~50 mV na voltagem
Risco: ⚠️ Moderado
☠️ REGRAS DE OURO DA VOLTAGEM:
✅ Máximo seguro 24/7: 1250 mV
⚠️ Limite absoluto: 1300 mV
☠️ Acima de 1300 mV = risco de danificar o chip (electromigration)!

🎯 Tabela de Overclock

Nível Frequência Voltagem Hashrate Consumo Temp Erros
🌿 Stock 400-525 MHz 1050 mV 1.0-1.2 TH/s ~15W ~45°C 0%
✅ Seguro 600 MHz 1150 mV ~1.3 TH/s ~20W ~50°C <1%
👍 Bom 700 MHz 1200 mV ~1.5 TH/s ~25W ~55°C <1%
⚡ Avançado 800 MHz 1250 mV ~1.6-1.7 TH/s ~30W ~60°C <2%
🔥 Extremo* 850-900 MHz 1250-1300 mV ~1.8+ TH/s ~35W+ ~65°C <2%

*Extremo requer TODOS os upgrades de cooling (heatsink pin-fin, pasta Kryonaut, heatsinks VRM, fonte 50W)

🌡️ Limites Térmicos

NUNCA ultrapasse estes limites!

✅ 45-55°C — Confortável ⚠️ 55-65°C — Aceitável 🔶 65-70°C — Atenção! 🔴 70-75°C — Throttling! ☠️ 75°C+ — PERIGO!
💡 Dica: Se passar de 65°C, você precisa de melhor cooling. Não adianta só abaixar a voltagem — invista em heatsink e pasta térmica de qualidade.

🔓 Destravando Configurações OC

No AxeOS, as opções de frequência e voltagem vêm ocultas por padrão:

1. Vá em Settings
2. Adicione ?oc no final da URL
3. Exemplo: http://192.168.1.100/settings?oc
4. Pronto! Os campos de Frequency e Core Voltage apareceram ✅

✅ Validação Final (72h)

Depois de achar sua configuração ideal, valide:

✅ Erros / shares rejeitados < 2%
✅ Temperatura sempre abaixo de 65°C
✅ Sem reboots inesperados
✅ Sem quedas bruscas de hashrate

🚨 Troubleshooting

🔄 Reboots aleatórios
Causa: Fonte insuficiente
✅ Troque para fonte de 50W (Mean Well)
🔥 VRM > 90°C
Causa: Sem heatsink nos MOSFETs
✅ Adicione dissipadores nos VRMs
❌ Muitos shares rejeitados
Causa: Voltagem baixa para frequência
✅ Aumente +25mV ou diminua -25MHz
📉 Hashrate oscilando
Causa: Throttling térmico
✅ Melhore o cooling
⚙️ Não aparece ?oc
Causa: URL errada
✅ Digite /settings?oc na barra de endereço
🌐 Não acha o Bitaxe
Causa: Roteador bloqueando
✅ Desligue AiProtection/IoT Protection
🔌 USB-C não reconhece
Causa: Problema conhecido
✅ Use adaptador USB-A para USB-C
📡 Sem hash após configurar
Causa: Config de pool errada
✅ Verifique URL, porta e wallet do pool
